# Android UI 适配 Spec

## 目标

复用现有 Flutter 页面、组件、主题和状态管理，在 Android 窄屏设备上完成可视化调试。第一阶段只解决 UI，不接入真实账号、文件系统、Go bridge 或上传下载服务。

## 复用边界

- 复用 `lib/main.dart`、`lib/app`、`lib/pages`、`lib/widgets`、`lib/theme` 和现有路由。
- Android 只新增平台壳 `android/` 和 UI 预览入口，不复制页面。
- `UI_PREVIEW=true` 时使用内存 mock API，启动后直接显示已配置的主界面。
- Windows/macOS 的窗口、托盘、FFI 和多窗口逻辑不参与 UI 预览。

## 验收尺寸

- 360x800：基础窄屏，不能出现横向溢出。
- 393x852：常见 Android 竖屏。
- 600x960：小平板/横屏切换前的中间宽度。

## 适配规则

- 宽度小于 700：内容全宽，桌面侧栏改为移动导航入口。
- 卡片和弹窗使用可用宽度减去 32px 内边距，不写死大于屏幕的宽度。
- 操作栏在窄屏折叠为滚动或更多菜单，不能裁切按钮。
- 列表优先保证名称和主操作可见，次要列允许隐藏。
- 所有纵向内容可滚动，软键盘弹出时输入框保持可见。

## 非目标

本阶段不实现 Android 原生挂载、桌面托盘、Go `.so` bridge、后台下载和发布签名。
