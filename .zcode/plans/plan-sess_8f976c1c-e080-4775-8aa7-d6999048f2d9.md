## 问题根因

上一版用了 `Flexible(flex:1, loose)` 包裹操作区，导致两个 bug：

1. **空位很大也只剩 `...`**：`Flexible(flex:1)` 把 Row 宽度按 1:1 分给标题和操作区。操作区拿到约半个页面宽度（~450px），但阈值是 520px → 450 < 520 → 永远判定"空间不足"，始终折叠成 `...`。
2. **`...` 菜单不在右侧**：`Flexible(loose)` 给操作区分配了一整块 flex 空间，`Wrap(alignment: end)` 只在这块空间的右端对齐，而不是整个 Row 的右端 → `...` 按钮停在中间偏右，而不是页面最右。

正确做法（来自 Flutter Row 布局规则）：
- **标题列**用 `Expanded`（贪婪，吃掉所有剩余空间）。
- **操作区**不用任何 `Flexible`/`Expanded`，让它按内容宽度布局；外面套 `ConstrainedBox(maxWidth: threshold)` 给一个上限。这样非 flex 的 Row 子节点先拿到 `maxWidth = rowWidth`（有界），被 `ConstrainedBox` 压到 threshold 上限，操作区取内容宽度（≤ threshold），`Expanded` 标题吃掉剩下的。操作区内层 `LayoutBuilder` 拿到的 `constraints.maxWidth` 才是真实可用的有界宽度。
- `overflowThreshold` 从 520 降到 **360**（四按钮 ~340px 自然宽 + 余量），`ConstrainedBox(maxWidth: 360)` 与之相等。宽窗口时操作区拿满 360、按钮全铺开、`LayoutBuilder` 看到 360 >= 360 → 展开；窄窗口时 Row 给操作区的空间 < 360 → 折叠成 `...`。

## 改动

### 1. `lib/widgets/page_header_actions.dart`
- `overflowThreshold` 默认值 `520` → `360`。
- `Wrap` 的 `alignment` 保持 `WrapAlignment.end`（操作区内右对齐）。因为操作区现在是非 flex 的内容宽度 widget，整个操作区本身会被 Row 自然推到标题右侧，`Wrap.end` 让按钮在操作区内右对齐，整体效果是按钮贴 Row 右边。

### 2. `lib/pages/transfers_page.dart`（头部 Row, ~276-328 行）
- 标题列：`Flexible(fit: tight, flex:1)` → **`Expanded`**。
- 操作区 `TransferTaskSelectionActions` 外面：去掉 `Flexible(fit: loose, flex:1)`，改为：
  ```dart
  ConstrainedBox(
    constraints: const BoxConstraints(maxWidth: 360),
    child: TransferTaskSelectionActions(...),
  )
  ```

### 3. `lib/pages/share_management_page.dart`（头部 Row, ~271-348 行）
- 标题列：`Flexible(fit: tight, flex:1)` → **`Expanded`**。
- 操作区（含选中/未选中两个分支的 PageHeaderActions）：去掉 `Flexible(fit: loose, flex:1)`，改为 `ConstrainedBox(constraints: BoxConstraints(maxWidth: 360), child: ...)`。

### 4. `lib/pages/global_trash_page_view.dart`（头部 Row, ~42-85 行）
- 标题列：`Flexible(fit: tight, flex:1)` → **`Expanded`**。
- 操作区 `GlobalTrashHeaderActions`：去掉 `Flexible(fit: loose, flex:1)`，改为 `ConstrainedBox(constraints: BoxConstraints(maxWidth: 360), child: ...)`。

### 5. `lib/pages/file_sync_tasks_page.dart`（头部 Row, ~86-127 行）
- 单按钮「新建配置」，不溢出，但标题列 `Flexible(tight, flex:1)` 改为 **`Expanded`**（与其它页一致，单按钮保持原样不套 ConstrainedBox）。

### 6. `lib/pages/cloud_storage_page.dart`（`_PageHeader` Row, ~223-254 行）
- 同上：单按钮「新增账号」，标题列 `Flexible(tight, flex:1)` → **`Expanded`**。

## 验证

- 所有文件仍 < 500 行。
- 交用户手动验证：任务队列/分享管理/回收站选中多项后，宽窗口按钮全平铺且贴右；缩窄窗口次要操作收进 `...` 菜单且 `...` 按钮仍在页面最右侧，点开菜单也在右侧弹出。
