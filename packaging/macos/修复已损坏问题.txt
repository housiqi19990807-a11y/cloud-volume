云卷 macOS 打开提示「已损坏」修复说明
============================================

如果下载 云卷.app 后 macOS 提示「已损坏，建议移到废纸篓」或「无法验证开发者」，
这是系统 Gatekeeper 对未签名发布包加上的隔离属性 (com.apple.quarantine)，
并不代表文件真的损坏。请按下面的步骤手动移除即可正常使用。

步骤
--------------------------------------------

1. 先把 云卷.app 拖到「应用程序 (Applications)」文件夹。

2. 打开「终端」(Terminal)：
   - 在「访达 (Finder)」里按 Command + Shift + U 打开「实用工具」，
     双击「终端」；
   - 或在「启动台 (Launchpad)」搜索「终端 / Terminal」。

3. 复制下面这一行命令，粘贴到终端里，按回车执行：

       xattr -dr com.apple.quarantine /Applications/云卷.app

   - 如果提示 「No such file or directory」，
     说明应用不在 /Applications 目录。请确认第 1 步已完成，
     或者把命令里的路径换成 云卷.app 实际所在的位置，
     例如解压在「下载」目录时用：

         xattr -dr com.apple.quarantine ~/Downloads/云卷.app

   - 如果提示 「Operation not permitted」，
     是因为终端没有访问「应用程序」的权限。
     请到「系统设置 -> 隐私与安全性 -> App 管理 / 完全磁盘访问权限」
     里允许当前使用的终端 App，然后重新执行。

4. 命令执行完成后没有输出即代表成功。
   现在再到「启动台」或「应用程序」里双击 云卷.app 即可正常打开。

为什么会有这个提示
--------------------------------------------

云卷目前没有使用 Apple 开发者证书签名，从网页下载的包会被系统自动加上
隔离属性，从而触发 Gatekeeper 的「已损坏」警告。手动执行上面的 xattr 命令
移除隔离属性后，应用就和正常签名包一样可以打开，对功能没有任何影响。
